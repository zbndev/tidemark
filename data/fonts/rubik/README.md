# Rubik

`Rubik%5Bwght%5D.ttf` is the exact variable font used by the Linux reference
desktop: `ttf-rubik-vf` 2.3.0-3, where the interface setting is `Rubik 11`.
It was copied from `/usr/share/fonts/TTF/Rubik%5Bwght%5D.ttf` on the reference
host on 2026-09-05.

- Font SHA-256: `1b3a7437ba2af80e465e773ed60c5036d1ba6ace492d89046dbcf18fb31e4e88`
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`
- Upstream: <https://github.com/googlefonts/rubik>

The Windows package keeps the font next to its GTK runtime and registers it
with Pango at startup. It never installs a font into Windows for the user.
